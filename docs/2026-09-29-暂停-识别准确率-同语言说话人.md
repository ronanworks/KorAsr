## 这文档解决什么问题

## 1. 暂停 / 继续

- **按钮**：录音中是"暂停 / 结束"，暂停后是"继续 / 结束"。
- **暂停时**：先处理完最后一句和当前这一分钟的精修，再释放麦克风。
- **继续时**：接着录同一节课。录音文件、时间轴、句子编号、精修进度、说话人编号都连着。
- **断网或断线**：自动按 2 s / 5 s / 10 s 重连，失败就进入"已暂停"，不再结束课堂。服务器重启时正在录的课也会变成"已暂停"。
- **课堂记录**：暂停中的课可以"继续上课"或"结束课堂"。时长只算实际录音。
- **测试**：后端 24 项、前端 10 项新测试。

## 2. 识别准确率

**评估方法**：从两段录音各抽约 50 句普通话、50 句韩语，每个系统用同一批片段。对错由我逐句判断，不是人工参考文本；依据是多引擎一致性和长上下文重识别的结果。汇总见 `asr_eval/judgment_counts.txt`，逐句见 `judgments.jsonl`。

| 普通话，52 句 | 明确错误＋严重 | 备注 |
|---|---|---|
| Whisper large-v3（原来） | 11 | 3 句输出繁体 |
| **SenseVoice-Small（现在）** | **5** | 无繁体；CPU 每句约 0.2 s，不占显存 |
| Qwen3-ASR-0.6B | 3 | 每句约 1 s，而且不能指定语言 |
| FireRedASR2 | 2 | CPU 上每句约 1.7 s，太慢 |

| 韩语，50 句 | 明确错误＋严重 |
|---|---|
| **Whisper large-v3（保持）** | **11** |
| large-v3-turbo | 14 |
| SenseVoice | 26 |
| ghost613 韩语微调 | 43（会凭空编出新闻句） |

**另外做的改进**：
- 6 s 强制切句后，下一句开头重复上一句结尾的词（如"싶었어요.｜싶었어요."），现在会去掉。韩语只在词边界处删，所以"남자친구｜남자친구가"会保留。
- Whisper 输出的中文统一转成简体。
- 补充中文幻觉黑名单："谢谢大家的观看"等。
- 翻译遇到识别错误时只输出"（听不清）"，不再写一段解释（"쏘랴 G"那句）。

**实测例子**：
- "消耗站垃圾站" → "消耗战、拉锯战"
- "先摸手出来" → "摸索出来一个新的路"
- "還不錯" → "还不错"

**试过但没采用**：
- 给中文加提示词"以下是普通话的句子。"：有两句真实语音被替换成"请不吝点赞 订阅…"和"优优独播剧场"。
- 用上一句当提示词：两种语言都没有净收益。

## 3. 同语言多人区分

**原因**：实时字幕按 ≤6 s 切片，每片只取一个声纹。快速对话时一片里有两个人，声纹被混在一起，只能归成一个人。在你测试录音的 58–164 s，20 句全部标成"说话人 1"。

**做法**：每分钟精修前，对这一分钟的音频做轮次级说话人分离：
- 用 pyannote 分段模型找出换人位置；
- 用 1.5 s 小窗声纹聚类判断是谁，编号和实时标签共用。

然后：
- 实时字幕里大部分由别人说的句子会被改标，界面随即更新；
- 精修按语言整段复识别并带词级时间戳，在换人处把词切开；
- 夹在别人话里、不到 1 s 的碎片并回前后那个人。

**评估**（`diarize/final/synth/synth_summary.json`）：3 位男声普通话、120 段合成对话。DER（说话人分离错误率，时长加权）如下：

| | 实时逐片标注 | 新方法 |
|---|---|---|
| 全部 | 0.290 | **0.094** |
| 最难的一对（leijun + liudehua） | 0.358 | 0.111 |
| 说话人数判对 | 63% | 99% |

**你的测试录音**：原来全标成一个人，现在精修卡片在两个声音间交替。例如"누나, 커플티 입어봤어요?"归男，"남자친구가 커플티를 사와서…"归女，"제 나이가 지금 서른…"归男。结果见 `replay_test_session_diarized/` 和 `e2e_diarize/`（经真实服务链路）。

**成本**：每分钟窗口 CPU 约 1.5 s，不占 GPU。启动时把 torch 限到 2 线程，因为默认 16 线程时每个窗口空转约 18 s CPU。

## 4. 已知限制

1. **换人边界精度约 0.5 s**：边界附近个别词会归错人，例如"…사려고 했는데 / 헤어졌어요"。插在别人话里的"네"会被并掉。
2. **实时字幕仍是一句一个标签**：一句里有两个人时，只标主要说话人。准确的轮次在每分钟精修卡片里，大约晚 1 分钟出现。
3. **新说话人的门槛**：一分钟里至少要说 4 s 才会新建编号，只问一句话的学生可能不单独编号。
4. **短句判错语言**：约 2 s 的短句偶尔判错。例如"半小时也看不懂"，Whisper 给出韩语 0.33、中文 0.14，被当成韩语识别，结果变成"3시간 뒤에 편집할게요"。
5. **准确率数字**：本文所有准确率都是模型判断或合成数据，没有人工参考文本。
